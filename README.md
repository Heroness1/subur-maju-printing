# Subur Maju Printing

Website landing page for Subur Maju Printing, inspired by the cinematic, editorial visual language of Kebun Bardja while keeping this project in a separate repository.

## Stack
- Next.js App Router
- React
- Lucide icons
- Responsive CSS with reduced-motion support

## Run locally
```bash
npm install
npm run dev
```

## Before production
- Confirm the official WhatsApp number and order flow.
- Replace/approve all stock photography for commercial use.
- Confirm service list, production hours, address, and turnaround claims.
- Connect analytics and verify conversion events before launch.
- Review metadata, canonical domain, sitemap, and structured data.

## Project principle
Reuse the visual direction—not orchard-specific content or assets. Keep Subur Maju business information accurate and avoid publishing unverified promises.
